# 找实习 SOP · BOSS 投递流程

把 BOSS 直聘投递做成一条可复用的流程：先筛岗，再打招呼，对方回复后只发一张按 JD 定制的简历，最后回写状态、复盘。

## 页面

- 首页：`index.html` —— 训练记录式开场 + 核心原则
- 完整 SOP：`boss-sop.html` —— 十岗机制、评分、招呼、定向简历、发送与跟进

线上地址：<https://rainyland.github.io/job-hunting-sop/>

## 这套流程的硬规则

- 本科及以上、线下日常实习、日薪 ≥120，优先 150+
- 优先近三天活跃 HR；旧帖、已读不回不反复追
- 每天分析 10 条真实 JD，不为凑数降标准
- 打招呼只发三段文字：岗位匹配 + 到岗安排 + 愿从基础做起
- 对方回复或明确要简历后，才发一张按 JD 定制的截图
- 一个会话只发一次简历；不重复发、不打扰在谈会话
- 不编造没做过的项目，不写不会的技能
